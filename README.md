##  Sobre o projeto

Este projeto foi desenvolvido como parte da **Atividade SAEP**, com o objetivo de colocar em prática conhecimentos de desenvolvimento web, utilizando **PHP**, **MySQL**, **HTML** e conceitos de gerenciamento de dados.

O sistema permite trabalhar com informações relacionadas a **candidatos e eleitores**, possibilitando operações de cadastro, visualização e exclusão de registros.

---

<div align="center">

|  📌 Funcionalidade | 💗 Descrição                                   |

|    👤 Candidatos   | Cadastro e gerenciamento de candidatos         |
|    🗳️ Eleitores   | Cadastro e gerenciamento de eleitores          |
|     ➕ Cadastro     | Formulários para inserção de dados             |
|   👀 Visualização  | Exibição dos registros cadastrados             |
|    🗑️ Exclusão    | Remoção de candidatos e eleitores              |

##  Como executar o projeto

### 1️ Clone o repositório

```bash
git clone https://github.com/joseaugusto271/atividade_saep.git
```

###  Entre na pasta

```bash
cd atividade_saep
```

### Configure o banco de dados

Utilize o arquivo:

```text
database.sql
```

para criar e configurar o banco de dados no **MySQL**.

###  Configure a conexão

Verifique o arquivo:

```text
config.php
```

e configure os dados de acesso ao banco de dados conforme o seu ambiente.

###  Execute o projeto

Utilize um ambiente de desenvolvimento local, como **XAMPP**, para iniciar o Apache e o MySQL.

Depois, acesse o projeto pelo navegador.

##  Organização do sistema

O projeto foi dividido em arquivos responsáveis por diferentes funções, facilitando a organização e manutenção do código.

###  Candidatos

* `candidatos.php` → gerenciamento/listagem dos candidatos
* `candidato_form.php` → formulário de candidato
* `candidato_excluir.php` → exclusão de candidato

###  Eleitores

* `eleitores.php` → gerenciamento/listagem dos eleitores
* `eleitor_form.php` → formulário de eleitor
* `eleitor_excluir.php` → exclusão de eleitor

###  Configuração

* `config.php` → configuração da conexão com o banco de dados
